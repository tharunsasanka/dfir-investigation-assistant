# Locked Project Scope

The project retains all requirements from the original DFIR prompt and adds only these eight research features:

1. Evidence-to-Conclusion Traceability
2. Cross-Evidence Correlation Engine
3. Confidence-Aware AI Findings
4. Investigation Hypothesis Board
5. Alternative Explanation Generator
6. Investigation Replay Mode
7. Built-In Evaluation Laboratory
8. Forensic Provenance and Reproducibility

No additional feature from the earlier extended list is part of the committed scope unless it is approved later through a documented change request.
